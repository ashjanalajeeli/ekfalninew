# Ekfalni — تطبيق ومنصة الكفالة والتبرعات

**Ekfalni** ليس مجرد نموذج تبرع؛ هو تجربة رقمية متكاملة تساعد المتبرع على اكتشاف فرص الأثر، اختيار حملة أو مستفيد، تجهيز تبرعاته، ثم متابعة رحلة الكفالة والتحديثات المرتبطة بها.

## فكرة المشروع

يجمع التطبيق بين الكفالة الفردية والتبرعات المالية والعينية في واجهة واحدة، مع الحفاظ على عرض إنساني ومحترم لملفات المستفيدين. يستطيع المستخدم استعراض الحملات، قراءة تفاصيل المستفيد، اختيار نوع التبرع، مراجعة العناصر في سلة التبرعات، ثم الانتقال إلى خيارات الدفع المتاحة.

## الواجهات الرئيسية

- **الرئيسية:** ملخص الأثر الشهري، الحملات التي تحتاج دعمًا، ونقاط الدخول السريعة للتبرع والكفالة.
- **لوحة المتبرع:** متابعة الكفالات النشطة، حالات الأيتام المكفولين، التقارير الدورية، والإحصاءات الشهرية للأثر.
- **تنبيهات التقارير:** مركز إشعارات وتفضيلات لاستلام تقرير اليتيم عبر إشعار فوري أو بريد إلكتروني.
- **السجل المالي:** كشف عمليات التبرع مع الإجمالي، التصفية حسب الحالة، وتفاصيل العملية.
- **تفاصيل التقرير الدوري:** قراءة ملخص الحالة والمؤشرات والتحديثات، مع فتح نسخة PDF للتنزيل.
- **لوحة المشرف:** مراجعة ملفات الأيتام، اعتماد التقارير الدورية أو طلب تعديلها، ومتابعة مؤشرات الجودة.
- **الرسوم التحليلية:** رسم تطور حالة الأيتام ومخطط المساهمات الشهرية ونسب العمليات المالية.
- **تصدير تقارير المشرف:** تصدير التقرير المالي والإحصائي بصيغة Excel أو PDF من الخادم بعد التحقق من دور المشرف.
- **إدارة الجمعيات:** إدارة الجمعيات والمشاريع والحالات وبيانات الأيتام بصلاحية `charity`.
- **طلبات الكفالة:** إرسال طلب كفالة، مراجعته، قبوله أو رفضه مع إشعار المتبرع ومنع التكرار في الكفالات النشطة.
- **المدفوعات والتدقيق:** إنشاء سجل دفع قابل للربط بمزود الدفع وسجل `audit_logs` لعمليات الإدارة.
- **الحالات والإشعارات الإدارية:** إدارة حالات اليتيم وإرسال إعلانات موجهة لكل المستخدمين أو دور محدد أو جمعية.
- **تفاصيل المستفيد:** قصة المستفيد، نوع الرعاية، الاحتياجات الحالية، نسبة التقدم، ومعلومات الخصوصية قبل بدء الكفالة.
- **سلة التبرعات:** مراجعة الحملات والعناصر المختارة، تعديلها أو حذفها، ومعرفة الإجمالي قبل إدخال بيانات التبرع.
- **التبرعات:** التبرع لمرة واحدة أو بشكل شهري، واختيار الفئة أو المشروع.
- **الكفالة:** اكتشاف فرص الكفالة، قراءة الشروط، متابعة الكفالات الحالية، وتأكيد رحلة الكفيل.
- **الجمعيات والمشاريع:** استعراض الجهات والمبادرات والمشاريع المرتبطة بها.
- **الملف الشخصي وسجل التبرعات:** إدارة البيانات الشخصية ومراجعة أثر المستخدم.

## التقنية

- Flutter وDart لتطبيقات Android وiOS.
- Riverpod لإدارة الحالة.
- Google Fonts وخط Cairo لدعم العربية وواجهة RTL.
- Firebase وواجهات API بحسب إعداد البيئة.
- Material 3 مع ثيم Ekfalni البنفسجي والذهبي.
- دعم التبرعات المالية والعينية، وسجل التبرعات، وخيارات الدفع الموجودة في المشروع.

## الهوية وتجربة الاستخدام

تم تحديث التصميم ليعكس شخصية Ekfalni: خلفيات هادئة، بنفسجي موثوق، ذهبي يرمز للأثر، بطاقات مستديرة، مؤشرات تقدم واضحة، وتنقل سفلي سريع بين الرئيسية والتبرعات والكفالة والجمعيات. الواجهات الجديدة مصممة لتكون مفهومة بالعربية ومتجاوبة مع الشاشات المختلفة.

## الحالة الحالية

الواجهات والتدفقات الأساسية جاهزة للعرض والتطوير، وتشمل صفحة تفاصيل المستفيد وسلة التبرعات ولوحة المتبرع والسجل المالي وتفاصيل التقرير الدوري مع تنزيل PDF. طبقة التنبيهات تحفظ التفضيلات محليًا وتزامنها مع مسارات API عند توفر الخادم. قبل الإطلاق التجاري يجب ربط خدمة الخلفية بموفر بريد وFCM/APNs، وربط حدث `report.created` بإرسال التنبيه إلى المتبرعين المعنيين، وتوفير مسار PDF موثق، إضافة إلى مراجعة الخصوصية واختبار بوابات الدفع على Android وiOS.

## Backend وقاعدة البيانات

يوجد Backend مستقل داخل [backend](backend/) باستخدام Node.js وExpress وPostgreSQL. يوفر JWT، أدوار `donor` و`charity` و`supervisor` و`admin`، إدارة الجمعيات والمشاريع وطلبات الكفالة، مراجعة التقارير، تصدير Excel/PDF، المدفوعات، وسجل التدقيق والإشعارات داخل التطبيق عبر REST وServer-Sent Events. راجعي [دليل تشغيل الخادم](backend/README.md) لتشغيل PostgreSQL وتطبيق المخططين `001` و`002`.

توجد اختبارات تكامل لمسارات المتبرع والمشرف في [TESTING.md](backend/TESTING.md)، وتعمل تلقائيًا على PostgreSQL 16 مع كل Pull Request أو push إلى `main`. كما يراقب GitHub Actions الثغرات أسبوعيًا، ويستخدم Dependabot لفتح تحديثات دورية للاعتماديات.

### عقد التنبيهات المقترح للخلفية

```text
PUT  /notifications/preferences   حفظ قنوات المتبرع المفضلة
POST /notifications/device-token  تسجيل رمز الجهاز للإشعارات الفورية
GET  /notifications               جلب تنبيهات وتقارير المتبرع
GET  /sponsorship-reports/:id/pdf تنزيل التقرير الدوري بصيغة PDF
GET  /admin/orphans                قائمة الأيتام للمشرف
GET  /admin/sponsorship-reports    التقارير بانتظار المراجعة
POST /admin/sponsorship-reports/:id/approve اعتماد التقرير أو طلب تعديله
GET  /admin/exports/:report?format=xlsx|pdf تصدير التقرير المالي أو الإحصائي
GET  /user/profile                 جلب الدور الحالي من قاعدة البيانات
```

عند صدور تقرير جديد، تنشئ الخلفية حدث `report.created` وتتحقق من تفضيلات المتبرع، ثم ترسل البريد والإشعار الفوري للقنوات المفعلة فقط.
